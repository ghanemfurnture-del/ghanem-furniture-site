# دليل إضافة لغة جديدة إلى موقع Ghanem Furniture
(How to Add a New Language)

تم تصميم نظام الترجمة الداخلي لموقع **Ghanem Furniture** بطريقة معيارية فائقة المرونة تتيح إضافة أي لغة جديدة (مثل الفرنسية `fr`، الألمانية `de`، الإيطالية `it`... إلخ) خلال دقائق وبدون تعديل هيكلي في الكود الأساسي.

---

## 3 خطوات بسيطة لإضافة لغة جديدة:

### 1. إنشاء ملف الترجمة الجديد
قم بنسخ ملف `lang/en.json` (أو `lang/ar.json`) وأعد تسميته برمز اللغة الجديدة، مثلاً:
`lang/fr.json` للفرنسية أو `lang/de.json` للألمانية.
ثم قم بترجمة القيم (Values) داخل الملف مع الحفاظ على أسماء المفاتيح (Keys) كما هي تماماً.

### 2. إضافة رمز اللغة إلى قائمة اللغات المدعومة في `js/i18n.js`
افتح ملف `js/i18n.js` وفي السطر رقم 8 أضف رمز اللغة الجديدة للمصفوفة `SUPPORTED_LANGS`:
```javascript
const SUPPORTED_LANGS = ['ar', 'en', 'fr'];
```

### 3. إضافة خيار اللغة في القائمة المنسدلة في الهيدر
في كود الـ Language Switcher في صفحات الـ HTML، أضف زراً للغة الجديدة داخل وسم `<div class="lang-dropdown">`:
```html
<button type="button" class="lang-option" data-lang="fr">
  <span class="lang-option-flag">🇫🇷</span>
  <span class="lang-option-name">Français</span>
</button>
```

---

## ميزات النظام:
- ✅ **حفظ التفضيل:** يتم حفظ اللغة المختارة في متصفح الزائر (`localStorage`) لتبقى مفعلة عند التنقل بين الصفحات والزيارات المستقبلية.
- ✅ **التبديل التلقائي للاتجاه (RTL / LTR):** يتم تغيير خاصيتي `dir` و `lang` في وسم `<html>` تلقائياً.
- ✅ **دعم ترجمة الخصائص:** يدعم النظام استبدال النصوص عبر `data-i18n`، وكذلك خصائص `placeholder` عبر `data-i18n-placeholder` و `title` عبر `data-i18n-title` و `alt` عبر `data-i18n-alt`.
- ✅ **Fallback آمن:** في حال تعذر تحميل ملف الترجمة لأي سبب، تظهر النصوص الأصلية في الصفحة دون أي انقطاع للخدمة.
